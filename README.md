# GPTCOM

Gemini sohbeti ve Windows indirmesi. Vercel Production ortamında GEMINI_API_KEY ekleyin. İsteğe bağlı GEMINI_MODEL; varsayılan gemini-3.5-flash-lite.

API anahtarı sunucuda tutulur. Sohbetler tarayıcıda saklanır. IP sınırı sunucu örneği başına 10 istek/dakika; hesap genelinde kota için Google AI Studio sınırlarını yapılandırın.
